# -mnogouga

Moja ideja za ovo rešenje zasniva se na vektorskom proizvodu. Ivice konveksnog mnogougla posmatrala sam kao usmerene vektore. Za svaku ivicu AB i tačku T formiraju se dva vektora. Znak rezultata njihovog vektorskog proizvoda nam govori  na kojoj se strani vektora AB nalazi tačka T. Kada je znak isti za sve ivice, to znači da se tačka nalazi unutar mnogougla.Da bi ovo rešenje funkcionisalo, uneta temena mnogougla moraju biti sortirana. Sortiranje je izvršeno u odnosu na njihovu centralnu tačku pomoću uglova. To je i jedan od glavnih razloga zašto sam izabrala Javu. Nudi odličnu podršku za kolekcije, koje sam koristila za sortiranje (liste) i sprečavanje unosa duplih temena (setovi).
